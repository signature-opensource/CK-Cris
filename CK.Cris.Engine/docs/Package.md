Setup-time engine for Cris. Not referenced by applications: it is loaded by the CKSetup engine, and
the Cris attributes name it by string.

It waits for the Poco type system - a command is a Poco, so nothing can be discovered before it -
then finds every command, event and handler method, sorts the handlers by kind, and checks what fits
together. Each ambient value property must have its non-nullable twin on an ambient values Poco, and
the error message writes out the declaration to add.

The model it publishes drives the code generators. It produces the command directory itself; the
execution code is generated by a separate engine reading the same model.
